# Roblox Developer Portfolio

A responsive, dark portfolio website for showcasing your Roblox projects.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — design and responsive layout
- `script.js` — name, Roblox game links, contact link, mobile navigation

## Before sharing it
1. Open `script.js` in a text editor.
2. Replace `YOUR NAME` with your display name.
3. Set `initial` to the first letter of your name.
4. Paste your Squid Game Roleplay URL into `squidGameUrl`.
5. Paste your Staff Training Center URL into `trainingCenterUrl`.
6. Paste your preferred contact link into `contactUrl`.
7. Replace the decorative project artwork in `index.html` with real screenshots from your games. The artwork is clearly illustrative and is not intended to represent actual gameplay.
8. Remove or edit any skill or project claims that don't accurately reflect your work.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example, `roblox-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait a few minutes for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

Do not share the portfolio until the links work and the placeholders have been replaced with real screenshots.
